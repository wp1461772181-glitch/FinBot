# 回滚禁令：S0 之前的代码树（2026-11-11 起）

2026-11-11，FP0（S0 停标）上线：旧数字核查线不再向用户可见答案写任何标记，
旧判定只进审计（`audit.legacy_review`），存量回合靠读时投影
（`app/agent_workflow/legacy_projection.py`）在展示时剥离旧痕迹。

## 规则

- **禁止把生产回滚到任何 S0 之前的代码树。** S0 之前的代码会重新对用户可见
  答案加旧标记（「数字未核实」脚注、（未核实）后缀、状态降级），等于把已退役
  的误标机制请回来；而且 `CLAIM_NUMBER_REVIEW=off` 与 S0 代码是配套的，
  旧代码配新开关（或反过来）都不在验收范围内。
- 盒子上所有 S0 之前的备份目录已改名带后缀 `-pre-s0-DO-NOT-ROLLBACK`，
  并在盒子 `/opt/finbot/ROLLBACK_FORBIDDEN` 留有清单。部署时新产生的
  S0 前备份（如部署当天的旧 live 树）同样要改名并登记。
- **回滚终点只能是「FP0 或其后」的状态**：正文照发、核查留影子
  （见 Fable 实施方案 §2.4）。出问题先关新包的开关（`FINBOT_<PKG>_<ABILITY>`），
  不要退回旧标记线。
- S0 的提交链：分支 `fp/fp0-s0`（2e1ec80 … eb4062f），2026-11-11 合并入
  main（合并提交 fc80d10）后部署。

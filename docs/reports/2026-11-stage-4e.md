# 阶段 4e：「它眼中的你」——一页看全它记得的和猜的，可改、可删、可导出

日期：2026-11-25（夜）。分支 `claude/stage4e`（在 `claude/stage4d` 之上；4d 的 PR 还没合并，所以 4e 叠在它上面，合并顺序必须是先 4d 后 4e）。计划 `docs/superpowers/plans/2026-11-25-stage4e-what-it-knows-about-you.md`（Opus 规划席写的，原样入库）。

## 结论

- **记忆页的「画像」页签改名为「它眼中的你」**（地址和 `?tab` 的值不变，旧链接不坏）。一页里从上到下：概览（它记了多少条：你说的、你写的、它推断的、你确认的推测、待你确认的推测、已归档、你的看法、在盯的；记忆整理的日程和上次结果）→ 你的看法 → 画像（原有的，没动）→ 它在帮你盯的 → 它每轮实际读到的。
- **你的看法在这一页能改、能撤回**：「改」产生一个新版本，旧版本留在历史里（和在对话里说一句效果一样）；「撤回」后它不再按这条看法回答，历史还在。每家公司显示所有版本（已更新、已撤回、已归档）和最新一次「回头看」（4d）。你在页面上手写的看法显示「在记忆页写的」，不再显示一段原话。
- **能整体导出**：JSON（完整）和 Markdown（好读）两种，一键下载。内容：每条画像（所有层、归档的、待确认的带例子）、每家公司看法的全部版本和回头看、盯防设置、记忆整理日程、它每轮读到的画像原文、对话摘要。不含对话原文、不含任何哈希或凭据（测试逐个字段核对）。被你否掉的推测库里只存了指纹、没有文字，导出里只说有几条。
- **它在帮你盯的**（只读，修改仍在各自的页面）：持仓计划（补仓/止损/目标价/文字计划）、盯盘任务、研究队列，以及一句实话：系统默认对持仓和研究队列盯价格异动与新公告，这些默认规则现在还不能按你单独调整。
- **它每轮实际读到的**：折叠区里原样显示默认助理每轮读到的画像文字，包括「另有 N 条未显示」那一行，被截断的东西不会被藏起来。
- **一部分读不出来不连累整页**：概览的每一块各自成败，哪块失败就只那一块显示错误条和重试。
- **模型能把你带到这一页**：`open_page` 能打开记忆页（问「你都记得我什么」时，它可以从自己已读到的画像回答，并给出这一页）。没有新工具，提示词没动。

## 计划里「待 owner 定」三条，按计划的推荐先行

1. 导出不含对话原文（只含对话摘要）；文件的说明里写明了，原文在往事页和每夜备份里。
2. 做成记忆页「画像」页签的改名，不新开页面。
3. 在页面上改看法不出确认卡，直接生效（历史版本保留，可查可删）。

## 和计划的差异（及理由）

1. **「在记忆页写的」的判断更严。** 计划写「`conversation_id` 为空就显示在记忆页写的」；但一条对话里记下、却没带对话编号的看法，原话就被藏起来了，违反「摆出依据」。现在要求同时满足「没有对话编号」且「原话为空或等于看法本身」才显示「在记忆页写的」，否则照常显示原话。
2. **`record_view`、`drop_view` 从「仅内核」改为登记在两条新路由上。** 计划要求这两条路由在操作登记表里对应这两个操作；已有测试规定登记表里的操作不能同时标为仅内核，所以 `KERNEL_ONLY_OPERATIONS` 现在是空的，对应的断言改成「不是仅内核」。模型自己的 `record_view` 路径没变，仍要求你的原话出处；页面这条路由由你本人亲手写，原话就是你写的字。
3. **`open_page` 加页面名 `memory` 会改变旧引擎的工具定义哈希**，而旧引擎的哈希有测试钉着。做法：旧引擎沿用原来的页面名列表（放在 `app/agent_tool_catalog_legacy.py`），只有新内核看到 `memory`；系统提示词没动。前端的客户端白名单（`agent-client-actions.mjs`）原本也不认 `memory`，模型发出打开记忆页的动作会被悄悄丢掉，已补上并加了测试。
4. **`ProfilePanel` 加了一个可选回调 `onChanged`**（写入成功后通知页面刷新概览数字和「读到的」块）。它自己的请求和行为没变；不加的话编辑画像后，页头的计数和「它每轮读到的」会过期。
5. 「撤回」确认用普通确认，不用长按（长按是给删除历史这种不可恢复动作的；撤回可以从历史里看到）。

# 5d-3b 后台「质量」栏：你的评价、被点不好的回答、尺子历次成绩

计划：`docs/superpowers/plans/2026-11-27-stage5d3b-quality-tab.md`。设计稿 §9.2「质量：被点『不好』的回答、每周自检的归类、尺子的历次成绩」，§10.1、§10.2。每周自检的归类在 5d-3c 加进来。

## 做了什么

- **尺子每次跑完多写一份 `meta.json`：** 开始和结束时间、哪套题、几道、对哪个地址、用什么模型、并行数，以及一句备注（`--note`，发布时我写提交号）。以前的结果只有摘要，看不出跑的是什么。
- **后台第七栏「质量」**（只读）：
  - **你的评价：** 最近 8 周，按回答所在的那一周（周一开始，北京时间）统计你点的「好」和「不好」，在对话里说的也算；没有评价的周显示 0。
  - **被点不好的回答：** 最近 20 条，带时间、bot、问题和你的原因；点开和「回答」栏一样看整个经过。
  - **尺子历次成绩：** 盒子上 `/opt/finbot/ruler-out` 里每一次结果（最多 50 次，最新的在前）：题数、通过率、答完时间的中位数和 P90、没过的题号。早期没有说明文件的标「早期记录，没有题库说明」；读不出来的列出名字。只读这个目录本身的子目录，不跟随链接。

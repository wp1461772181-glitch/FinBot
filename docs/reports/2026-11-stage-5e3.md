# 5e-3 财报跟进写明实际比预期高还是低

设计稿 §7.4（一致预期用于事前准备和事后对比）。数据来自 5e-1 的财报日历。

## 做了什么

- 财报一出（8-K Item 2.02），现在的第一条跟进消息在「关键数字（对比上季指引）」后面多一段，由代码写：
  - 「对比市场预期（Finnhub，调整后口径）」
  - 营收：实际 X B，预期 Y B，比预期高或低多少（差在 0.05% 以内写「与预期持平」）
  - 每股收益（非 GAAP）：实际、预期、高或低多少
- 预期取日历里这家公司财报日前后 3 天内最近的那一行（就是财报前一天那份，还没被事后数字覆盖）。日历里没有这一季：写「这一季没有拿到市场预期」，不留空。新闻稿里没取到实际数：只写预期，并注明没取到实际数。
- 读日历出错：这一段不出现，消息照常发。
- **口径的实证（11-27 在盒上只读比对）：** Finnhub 给的「实际每股收益」和系统自己从财报里抽出的数对照——
  - AMD 近三季：Finnhub 2.09 / 1.66 / 1.37，系统抽出的非 GAAP 2.09 / 1.66 / 1.37，GAAP 1.46 / 1.38 / 0.84。和非 GAAP 完全一致，所以 Finnhub 的每股收益是调整后口径。
  - 苹果（只公布 GAAP）：Finnhub 2.1 / 2.01 对 GAAP 2.1 / 2.01 一致；有一季 1.91 对 2.02 不一致。只给 GAAP 的公司，Finnhub 用的就是公布的那个数，大体可比，但不保证。
  - 所以：新闻稿有非 GAAP 就拿它比；只有 GAAP 时也比，但写明「新闻稿只给了 GAAP 每股收益，和预期的调整后口径可能不同」。

## Fable 验收（有条件通过）后改的

- **营收精度：** 新闻稿常只写一位小数（「$15.8 billion」），而预期精确到美元；差距在实际数自己的精度以内时写「与预期大致持平（新闻稿实际数只到小数点后 1 位）」，不判高低（原来 15.76 抽成 15.8 时会写成「比预期高」）。
- **每股收益用美元差：** 「比预期高 0.06 美元（22.0%）」；预期不到 0.10 美元时不写百分比（预期 0.01、实际 0.05 原来会写「高 400%」）；差在半分钱以内算持平（0.25 对 0.2541 不再写「低 1.6%」）。
- **只有 GAAP 的公司：** 见上面的实证，拿 GAAP 比并注明口径可能不同；原来会写「没取到实际数」，不对。
- **量级对不上（多半是单位漏标）：** 不判高低，写「量级对不上，可能是单位问题，请以原文为准」。预期营收为 0 当作没有预期。
- **标题写明是哪一季、什么时候拉的：** 「对比市场预期（Finnhub，调整后口径；FY2026 Q4，01-20 06:00 拉取）」，你可以自己核对对的是不是这一季。

## 没有实测的

- 线上真的出一次财报：你关注的公司最近一次在 2027-01-20（英特尔）。

## 测试

- 按财报日找日历行（前后 3 天内最近、范围外没有、别的公司没有）。
- 「对比市场预期」的写法：高、低、持平、没取到实际数、没有预期。
- 完整走一遍财报处理：第一条消息里这一段在「新指引」前面；日历出错时这一段不出现、消息照常。

# 5e-3 财报跟进写明实际比预期高还是低

设计稿 §7.4（一致预期用于事前准备和事后对比）。数据来自 5e-1 的财报日历。

## 做了什么

- 财报一出（8-K Item 2.02），现在的第一条跟进消息在「关键数字（对比上季指引）」后面多一段，由代码写：
  - 「对比市场预期（Finnhub，调整后口径）」
  - 营收：实际 X B，预期 Y B，比预期高或低多少（差在 0.05% 以内写「与预期持平」）
  - 每股收益（非 GAAP）：实际、预期、高或低多少
- 预期取日历里这家公司财报日前后 3 天内最近的那一行（就是财报前一天那份，还没被事后数字覆盖）。日历里没有这一季：写「这一季没有拿到市场预期」，不留空。新闻稿里没取到实际数：只写预期，并注明没取到实际数。
- 读日历出错：这一段不出现，消息照常发。
- 每股收益两边都是调整后（非 GAAP）口径，可以直接比；营收没有口径差别。

## 没有实测的

- 线上真的出一次财报：你关注的公司最近一次在 2027-01-20（英特尔）。

## 测试

- 按财报日找日历行（前后 3 天内最近、范围外没有、别的公司没有）。
- 「对比市场预期」的写法：高、低、持平、没取到实际数、没有预期。
- 完整走一遍财报处理：第一条消息里这一段在「新指引」前面；日历出错时这一段不出现、消息照常。

# 阶段 3d：小助手——跑腿派出去，判断留在自己手里

日期：2026-11-25。分支 `claude/stage3d`（在 3c 之上）。**还没有上线**，开关默认关。

## 结论

- **新工具 `delegate`（交给小助手）。** 一件跑腿活本身要好几步时（比如读三份电话会、各摘出资本开支的说法），回答它的那一轮可以把这件事连同一段交代交给小助手。小助手是一个只活一会儿的低档运行：只看得到交代，看不到对话；只有只读工具和计算，不能写、不能提问、不能再往下派。做完交回一段简短结果，并列出它读过的资料编号。这些编号就是这一轮的引用编号，回答里可以直接引用；它读过的网页也能被「保存」操作用到。
- **对比、判断、写结论不派出去。** 这一点写在工具说明里。小助手自己的提示也写明只报找到了什么、找不到的直说，不下判断、不给建议。
- **同时最多三件。** 一步里最多交出三件，同时跑；第四件当场回一句「一步里最多 3 件」，不占名额。小助手不占这一轮普通查询的并发名额。
- **上限：** 每个小助手最多 6 步、120 秒（硬上限，卡在某一次调用上也会到点收尾），到上限时再给它一步、最多 20 秒，用已有资料收尾。没写出总结时，由系统按它读过的资料列出编号（「还没写总结，已拿到的资料见 [n]…」）；一点资料都没拿到才算失败。失败了这一轮照常继续，可以自己查。小助手内部不切备用模型。
- **你插话时：** 小助手在下一步开始前看到这一轮收到了你的新消息，就会停下、交回已有的东西，这一轮马上处理你的话（3c 的规则）。你说停，它读到的资料也不会白丢。
- **安全：** 小助手只要真的跑了，这一轮就算看过一次外部资料。之后那种「看过资料就要出卡片」的直接写操作，一律出卡片让你按。这一条是自动安全检查发现、我修正了计划后加上的。
- **用哪个模型：** 设置页「角色 → 模型」新增一行「小助手」，不选就用当时对话的模型（这一轮已切到备用的，就用备用的）。永远是低档。
- **记录：** 小助手的模型调用在用量账本里记作「小助手」（单独一类）；后台的单轮详情里，每个小助手一行：模型、几步、读了什么、做完没有、用了几秒；这一轮的总调用数和 token 包含它。
- **开关 `FINBOT_HELPER`，默认关。** 关着时，所有对话的工具、提示与今天完全一样（测试用哈希钉住）。唯一的例外是给模型看的「后台角色」列表多了 helper 这个名字，因为角色本身不受开关控制。

# 阶段 4d：复盘——每季回看你以前对公司的看法

日期：2026-11-25（夜）。分支 `claude/stage4d`（在 main `c5ccbfd` 之上）。计划 `docs/superpowers/plans/2026-11-25-stage4d-view-review.md`。

## 结论

- **每季整理时，系统回看你以前对公司的看法**：成立 / 没有成立 / 部分成立 / 还早 / 说不准，并说你当时给的理由现在还在不在。第一次在 2027-02-15 的每季整理里跑。
- **输入全由代码拼好**：你当时的原话和日期、说话时已有的最后一个收盘价与最新收盘价（涨跌幅由代码算）、最新一季的财报数字。模型只写判断，不填表、不引用、不贴标签。
- **复盘原样保存，只标注、不删改。** 模型的话里如果出现既不在资料里、也不是对资料的简单计算的数字，公司页会在复盘下注明「这几个数字不在系统给的资料里，请自己核对：…」，每季那条消息里也带同样的注明。没有这种数字就什么都不显示。
- **显示位置**：公司页「你的看法」卡里，当前看法和每个历史版本下的「回头看」块（结论、原文、依据行「说的时候 $X → 现在 $Y（+Z%）· 最新一季 FYxx Qx」，缺的部分直接省略）；每季那条变更说明多一节「复盘：」。
- **失败不连累整理**：复盘出错、模型没回、读库慢，都只记日志，每季整理本身照常 `done`；这个看法留到下一季再试。

## 和交接单、计划的差异（及理由）

1. **「输出里的每个数字都必须出自输入」没有做成拦截，改为标注。** 照字面做会删改模型的复盘，与 CLAUDE.md 第 1、2 条冲突。标注针对的是编造的数字，模型对输入做的合理计算不标。
2. **标注规则两次收紧误报。** 独立审查发现：最初让所有数字两两配对（包括比例对比例），一个正常的季度下 99 个整数百分比里有 89 个能蒙混过去，编造的「同比增长 37%」标不出来。现在只允许：说话时价格、最新价格、他原话里的数字之间的计算，以及各项财报数字相对营收的占比和差额；比例值本身及其百分数直接算「出自资料」。同一个探针下蒙混通过的从 89 个降到 25 个，且编造的 37% 能标出。另一方面，用数字写的日期（2026-11-24、9/26）、分数（1/3）、计数（3 个理由、5 条、6 成）、带数字的名字（GPT-5）不再被误标；「3 个百分点」仍算数字。
3. **「说话时的价格」改为他说话时市场上已经存在的最后一个收盘价**（美东 16:30 前说的取前一天，之后取当天）。计划原写「说话当天或之前的最后一个收盘」，会让他早上说的话对上当天晚上才有的收盘价。
4. **价格序列停在他说话之前时没有「现在」，也没有涨跌幅**，不再显示「$110 → $110（+0.0%）」。
5. **日期用北京日期**（和页面一致）；读库超时从聊天块的 1.2 秒放宽到 15 秒（后台任务，慢一点不该次次失败）。
6. **每季先复盘从未复盘过的看法**，再复盘到期该再看的（最久没看的在前），避免每季都是同十个老看法占满名额、新看法永远排不上。
7. 计划里「刚被归档的看法不复盘」「活跃的看法 80 天后再看一次」「被取代或撤回的版本只看一次」「一次最多 10 条、总时限 240 秒」按原样实现。每季任务在待办里的标题改成「每季整理记忆（含看法复盘）」。
